# Block 88

A neighbourhood game set in a Singapore HDB estate, built for tablets. Help your neighbours, light up every window, then ride bus 36 around Singapore.

## Play

Open `index.html` in a browser. It is a single file with no build step. Best played in landscape.

To host it with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## What is in it

- Neighbour errands that light up windows on Blk 88
- A full estate: void deck, kopitiam, shops, food centre, wet market, MRT, bus interchange, reservoir park
- Old-school games (five stones, chapteh, goli, hopscotch, zero point) and food games
- Town projects funded with kampung points, including lift upgrading
- Bus 36 city loop with five districts
- "Be someone else today": spend a day as Uncle Rahim, Ah Ma Lim, Auntie Kavitha, Kopi Uncle, Uncle Muthu or the karung guni uncle
- A 40th anniversary finale for the block
- A void deck noticeboard of small favours, and a kindness journal that fills in as you help
- Seven community levels, from Quiet Neighbour to Heart of Tembusu, each opening bigger projects: a block clean-up, a get-together, a donation drive, a residents' meeting and Lights Night
- Introductions: bring together neighbours who have never spoken, and watch the who-knows-who web grow
- "Ask a grown-up you know": six questions to ask a parent, grandparent or neighbour, with their answers kept in the journal
- A seven-chapter story about a torn 1985 photograph of the block, taken the night a lantern glowed on every corridor. The pieces you find are pinned up on the back of the noticeboard
- Days: each visit is a new day. The neighbours have errands again, and everything you built, every friendship and the whole journal are still there

## Notes

Prototype. Progress is saved in the browser on the same device: community level, journal, introductions, grown-up stories, story chapters, discovered places, town projects (including the lift upgrade and the repaint), friendships, the album and your anniversary gift. Nothing is sent anywhere. The day's errands and lit windows start fresh each visit. Menu → Start a new story erases the saved progress.

Made for landscape tablets. It also lays out for phones held sideways, and shows a turn-your-device hint in portrait.

Built with Three.js (loaded from a CDN, so it needs an internet connection). Level titles are made up for the game and are not real grassroots positions.
